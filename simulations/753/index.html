Graphs

  • Brandes edge betweenness

    Count shortest paths breadth first. Send credit back through their parents in reverse order.

  • Clustering coefficient

    Inspect every pair of neighbours around a vertex to see which possible triangles close.

  • Fiedler spectral partition

    Use the second-smallest Laplacian eigenvector to split connected vertices into two groups.

  • Girvan–Newman community detection

    Remove one highest-betweenness edge and measure the remaining graph again. Ties follow input order.

  • Graph cuts

    Try every two-sided partition of a small graph and compare the cost under three objectives.

  • Greedy Newman modularity

    Start with one community per vertex and merge the pair with the greatest gain in modularity.

  • Link farm

    Trace the feedback between a target and its supporting pages. Change the farm size to measure its effect.

  • PageRank

    At link probability 1, the walk follows every available link step without ordinary teleportation. Walks at dead ends still restart uniformly.

  • Personalised PageRank

    Watch a chosen restart set change where a walk spends its time.

  • Spectral clustering with k-means

    Embed each vertex in the lowest Laplacian eigenvectors and run k-means on those rows.

  • TrustRank and spam mass

    Compare uniform PageRank with a walk that restarts on a trusted directory.

Hashing and similarity

  • AND/OR amplification and sensitivity

    Tune independent MinHash tests for near and far pairs. Depth separates the base, AND and OR stages. Height gives the collision probability.

  • Carter–Wegman universal hashing

    Pack two base-17 fields into one number. A random nonzero multiplier and offset send distinct keys to distinct field residues before folding into slots. The collision probability is at most 1 / slots.

  • Chained hash dictionary

    Insert keys, search a bucket and unlink a matching entry. Depth measures position in the chain.

  • Character shingles and Jaccard similarity

    Slide a window along each string. Each distinct shingle occupies one column, with a depth layer for each document.

  • LSH signature banding

    Partition eight signature rows into equal bands. Depth separates bands, horizontal position identifies a row and height separates documents.

  • MinHash by row permutation

    Scan a shuffled feature order until each set records its first rank. Height shows the rank and depth identifies the set.

  • One-pass MinHash

    Estimate agreement among the 42 affine permutations modulo seven in one pass. A uniformly shuffled feature order gives the Jaccard collision probability. Restricting the order to affine maps can change that probability.

  • SimHash by random hyperplanes

    Sample a plane with three independent standard normal coordinates for its normal. Its orientation is uniform in space. Two nonzero vectors at angle θ have matching sign bits with probability 1 − θ/π.

Influence

  • Exact live-edge spread

    Enumerate every live or blocked configuration of a small independent-cascade graph. Weight each reachable set by the probability of its configuration.

  • Greedy influence maximisation

    Add the node with the largest gain in expected spread. Recalculate every remaining gain after each choice. Alphabetical order breaks ties.

  • Independent cascade

    Follow a relay from its starting nodes. Each newly active node gets one independent attempt on each inactive neighbour.

  • Linear threshold

    Each node draws a threshold once. At each wave, add the weights from already active neighbours and compare the sum with that threshold.

  • Mutually exclusive cascade

    Each node independently picks at most one incoming edge. Its parent can activate it only if the relay reaches that parent.

Latent factors

  • Latent factors with stochastic gradient descent

    Learn one vector per user and item from observed ratings. Compare their dot products with and without learned bias offsets.

  • Truncated singular value decomposition

    Decompose a complete ratings table into rank-one patterns. Reconstruct the table and measure what the discarded pattern costs.

Nearest-neighbour search

  • Exact nearest-neighbour scan

    Measure every point against the query. Watch the nearest k change as each point arrives.

  • Greedy graph search

    Expand the closest discovered point first. The expansion budget decides how far the search can travel from its entry point.

  • Hierarchical navigable small-world graph

    Insert points into nested graph layers, then route a query from the highest layer to the base. Each layer view shows the original three coordinates.

  • Inverted file search

    Index points by their closest trained centre. Probe the nearest lists and measure the original vectors inside them.

  • K-means coarse codebook training

    Train a small set of representatives for an inverted index. Each update moves one centre to the mean of its assigned points.

  • Locality-sensitive hashing for a radius query

    When a point lies within the target radius, the search aims to find one within factor × radius. Random coordinate cuts form the bits. Match every bit in one table to become a candidate.

  • Product quantization distance lookup

    Split four coordinates into two pairs and store one code per pair. Compare an uncompressed query to these codes by adding two lookup entries. The plot shows the first three coordinates.

Randomised algorithms

  • Bounded Monte Carlo find-a

    Probe uniform random positions with replacement. A miss at the probe limit is inconclusive.

  • Card guessing

    Guess before turning over each card. Compare the number correct with the expectation for the chosen memory rule.

  • Coupon collector

    Draw uniform coupons with replacement until each type has appeared. Watch the probability of finding a new type fall as the collection grows.

  • Las Vegas find-a

    Probe uniform random positions with replacement until an a is found. Every successful return identifies its position.

  • Random-pivot quickselect

    Partition around a random pivot. Continue only in the part containing the requested rank. Equal values occupy consecutive ranks.

  • Random-pivot quicksort

    Choose a random pivot in each subarray. Group smaller, equal and larger values, then sort the two outer groups.

Recommenders

  • Bias baseline and residual prediction

    Estimate a usual rating from user and item biases. Correct it with the neighbours’ weighted surprises.

  • Content ranking with TF-IDF

    Turn tag counts into item profiles. Rank unread titles by their cosine similarity to a reader’s liked titles.

  • Item-based collaborative filtering

    Compare items to fill one missing rating. Inspect how common observations and negative similarities affect the estimate.

  • Learning interpolation weights

    Fit two neighbour weights by minimising the sum of squared errors on Ada’s observed ratings. Apply them to the neighbours’ residuals on Fir.

  • Precision, recall and ROC area

    Evaluate a scored list against held-out likes. Sweep a score threshold through tied groups to draw the ROC curve.

  • Root mean squared rating error

    Compare predictions with held-out ratings on the same scale. Shift every prediction to see how calibration changes the error.

  • User-based collaborative filtering

    Compare users to fill one missing rating. Inspect how common observations and negative similarities affect the estimate.

Streams and sketches

  • Count-Min Sketch

    Hash each tag to one counter per row. Other tags can inflate those counters, so take the smallest reading.

  • Fixed-proportion key sampling

    Hash each bird tag into one of six buckets. Every sighting of a tag follows its first sighting into or out of the sample.

  • Misra–Gries frequent items

    Keep a short list of candidate tags. When every counter is occupied, cancel one sighting of each candidate together with the incoming sighting.

  • Partitioned Bloom filter

    Each hash owns an equal slice of the bit array. A query checks one bit in each slice.

  • Repeated Bloom filter

    Insert each tag into independent copies. A membership query passes only when every copy accepts it.

  • Reservoir sampling

    Draw a uniform sample of sightings as they arrive. One slot gives RS1, several give RSs, and independent copies can sample the same sighting.

  • Signed Count Sketch

    Signed counters can move below zero. Undo the tag’s sign in each row and take the median to estimate its frequency.

  • Standard Bloom filter

    Several hashes set bits in one shared array. A zero at any queried address proves the tag is absent.
