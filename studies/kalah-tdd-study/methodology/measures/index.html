Measurement pipeline

Columns

Grade, size, mutation, static analysis, bench and rating columns read the method's final clone. Tokens, weighted tokens, agent calls and audit flags sum every clone of the method. Wall time spans every clone of the method from the first to the last transcript timestamp. Multi-start TDD has a final clone and 3 start clones. Costs, times, agent calls and audit flags leave out the 15 unattributed agents listed in RUN.md and in the Run section of report.html. The reference row's medians come from calibration round round-b.

Tests

Functional mark /15. Source: grade.tsv. Tag: recomputed.

Definition: A02-RUBRIC.md functional mark: 2 for the original set with no failure, 3 per other set less one per failure, and 4 when every test passes. A02 is the course assignment whose spec and rubric the experiment uses. STA means anticlockwise and STC clockwise sowing. 6-4 and 7-5 are houses and seeds. A02-RUBRIC.md names the original set "Clockwise 6 Houses 4 Seeds". This page names each set by the spec folder its tests play, so the original set reads STA 6-4.

Module: not stated in the snapshot.

Hidden pass /76. Source: summary.json. Tag: recomputed.

Definition: Hidden TestKalah tests passed by the final clone's src/.

Module: not stated in the snapshot.

Unseen pass /69. Source: summary.json. Tag: recomputed.

Definition: Hidden tests passed among the 69 whose specs no clone saw.

Module: not stated in the snapshot.

Acceptance pass /6. Source: grade.tsv, seen.tsv. Tag: recomputed.

Definition: Tests passed among the six whose seen.tsv source is an example spec.

Module: not stated in the snapshot.

Hidden, seen, unseen and acceptance tests. Tag: verified.

Definition: Hidden tests are the 76 TestKalah tests of the A02 course test suite, kept from every agent and used for grading. Seen tests are the 7 hidden tests whose specs the starter shows, as harness/grade/seen.tsv lists them. Six come as example spec files in examples/specs and one as the STA 6-4 simple_start spec quoted in the starter README. Unseen tests are the other 69. Acceptance tests are the 6 seen tests with example spec files, so the README test counts as seen only.

Inputs: harness/grade/seen.tsv, as the glossary row states.

Definition: Strict PMD compliance passes when PMD with the starter's kalah_pmd.xml finds no violation in src/ and otherwise fails with the count of distinct violations. The lint sets no minimum priority, so rules of every priority count. It covers src/ only, the scope of the starter's ./run.sh lint. Cost

Tokens. Source: costs.json from transcripts. Tag: recomputed.

Definition: Input, cache creation, cache read and output tokens over every agent of the method's clones.

Module: not stated in the snapshot.

Weighted tokens. Source: costs.json from transcripts. Tag: recomputed.

Definition: Weighted tokens count input 1, cache creation 1.25, cache read 0.05 and output 5 per token. These are claude-opus-5-5 prices relative to an input token and state no dollar cost. Summed over every agent of the method's clones.

Formula: 1 × input + 1.25 × cache creation + 0.05 × cache read + 5 × output

Module: not stated in the snapshot.

Wall time. Source: costs.json. Tag: recomputed.

Definition: First to last transcript timestamp over the method's clones, as h:mm:ss.

Module: not stated in the snapshot.

Agent calls. Source: costs.json. Tag: recomputed.

Definition: Workflow agents started for the method's clones, any without a transcript included.

Module: not stated in the snapshot.

Run order. Source: costs.json. Tag: recomputed.

Definition: Parallel when the method's first to last transcript span overlaps every other method's, else its start rank as start k of N methods with costs.

Module: not stated in the snapshot.

Cost to completion. Source: curve.json from costs.json with steps.csv for a method or batch.json tcp.calls for an arm. Tag: recomputed.

Definition: Weighted tokens of the lead cost plus the final clone's step costs, measure and review agents left out. A method's steps are the steps.csv rows of its graded points. An arm's steps are its loop calls, each costed by the costs.json agent its batch.json tcp.calls label names. A stopped call without a sha counts though it grades no point.

Module: harness/report/curve.py, as the glossary row Cost to completion states.

Also labelled: Weighted tokens to completion; Median cost to completion.

M. Source: curve.json mean_cost_to_pass with Cost to completion's costs.json, steps.csv or batch.json tcp.calls. Tag: recomputed.

Definition: Mean weighted-token cost to pass a hidden test: the cost to completion times 1 minus APFDc-H, the area above the hidden-suite pass share. A lower M costs less.

Formula: cost to completion × (1 − APFDc-H)

Module: harness/report/curve.py, as the glossary row M and M_io states.

Also labelled: M, weighted tokens per hidden test passed.

M_io. Source: curve.json mean_cost_to_pass_io with Cost to completion's costs.json, steps.csv or batch.json tcp.calls. Tag: recomputed.

Definition: M with output tokens left out of every cost, so it compares across CLI builds whose output per request differs.

Module: harness/report/curve.py, as the glossary row M and M_io states.

Combined and consistency

Awards and E. Tag: verified.

Definition: The Headline's awards rank the survey methods, lower first, with ties sharing a place. E sums a final's distinct PMD findings, adjusted surviving mutants, hidden failures and unseen failures. Alignment needs the blind CQP rating to agree with PMD on every principle and PMD to report no issue. Best overall is the plain sum of each method's ranks on M among 15/15 methods, E and alignment. Cheapest, the lowest cost to completion, and most consistent design, the lowest C pooled over every replicate of rep-1 and rep-2, take bronze badges only and never count toward best overall. A medal only styles a place and carries no score. harness/report/awards.py defines them.

Formula: distinct PMD findings + adjusted surviving mutants + hidden failures + unseen failures

Inputs: the Sources of Static analysis violations (metrics.json from pmd.txt), Adjusted mutation (metrics.json), Hidden pass /76 (summary.json) and Unseen pass /69 (summary.json).

Function error_count doc: E: distinct PMD findings, adjusted surviving mutants, hidden failures and unseen failures, None when any is unmeasured.

Module: harness/report/awards.py.

Relative spread. Source: replicate.py. Tag: recomputed.

Definition: A method's mean absolute deviation from its own median over the mean deviation of the replicated methods off the metric's bound. 1 is the average. At bound means at least 60 percent of builds sit at the bound and not comparable that fewer than two methods sit off it.

Module: replicate.py.

Consistency score C. Source: replicate.py. Tag: recomputed.

Definition: The mean relative spread over unadjusted mutation, classes and cost to completion. Exploratory.

Module: replicate.py.

Also labelled: Consistency score.

Test order measures

APFD-I. Tag: verified.

Definition: The area under a clone's hidden-pass curve over its steps, normalised to 0 to 1. Higher means hidden tests start to pass earlier. harness/report/curve.py defines it.

Inputs: not stated in the snapshot.

Module: harness/report/curve.py.

APFDc-H. Source: curve.json from curve.tsv and costs.json with steps.csv for a method or batch.json tcp.calls for an arm. Tag: recomputed.

Definition: Area under the final clone's hidden-suite pass share over cumulative weighted tokens, divided by the cost to completion. The lead cost, the lister's tokens for an arm or the start clones' for a method with start clones, comes first at the starter's pass share. An arm's stopped call without a sha adds its cost at the pass share before it.

Module: harness/report/curve.py, as the glossary row APFDc-H states.

Kendall distance. Tag: verified.

Definition: The share of test pairs that two orders rank differently. It is 0 for the same order and 1 for the reverse.

Inputs: not stated in the snapshot.

Module: not stated in the snapshot.

U. Tag: unchecked.

Definition: The Mann-Whitney U statistic of a contrast.

Function mann_whitney_exact doc: (U, p) of the exact two-sided Mann-Whitney test. U counts the pairs with x above y, ties as half. p is the share of every split of the pooled average ranks into a group of len(xs) whose rank sum lies at least as far from its mean as the observed, so ties stay exact. The C(n, len(xs)) splits suit small samples only.

Table header in: Contrast table (rep-1) and Contrast table (rep-2). Table header on Results: planned contrasts.

p. Tag: unchecked.

Definition: The p value of a test before Holm correction. The Holm p column corrects it.

Table header in: Contrast table (rep-1) and Contrast table (rep-2).

Permutation p. Tag: unchecked.

Definition: The p value of a seeded permutation test.

Function brown_forsythe_permutation doc: (F, p) of brown_forsythe. p is the share of seeded shuffles of the pooled deviations from each value's own group median over groups of the same sizes, counting the observed one, whose F reaches the observed. Shuffling raw values would mix the group medians into the spread.
